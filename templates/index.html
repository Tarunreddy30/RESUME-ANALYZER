About this project

  • AI part: the pretrained model all-MiniLM-L6-v2 (Sentence Transformers) turns text into embeddings; cosine similarity compares them.
  • Rule-based parts: PDF text extraction, skill detection (regular expressions + a skill dictionary), section checks and suggestions.
  • Privacy: your PDF is processed in memory and is not saved by this app.
  • Limitations: the skill dictionary is limited; scanned (image) PDFs are not supported; the score is only a rough guide.
